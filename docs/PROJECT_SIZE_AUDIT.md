# Project Size Audit

Audit date: 2026-09-22
Scope: `OpenISave2/` (the development directory). User data in
`%LOCALAPPDATA%\OpenISave2\` is **outside** this folder and was not scanned for
size, moved or modified.

## Total size before cleanup

**2,983 MB (≈2.9 GB) across 43,228 files.**

Source code, docs, scripts, lockfiles, icons and `logo.png` together account for
roughly **2 MB**. Everything else is regenerable build output or installed
dependencies.

## Largest causes of the size

1. **Two full Rust builds (≈2.5 GB, 85%).** `desktop/target` holds both a
   `release` build (LTO, `codegen-units = 1`, large intermediate objects) and a
   `debug` build left over from `tauri dev`. Tauri pulls in ~450 crates
   (WebView2, windows-rs, serde, tokio …), each compiled with debug info and
   metadata for both profiles.
2. **`frontend/node_modules` (≈250 MB, 8%).** antd + @ant-design icons,
   TypeScript, Vitest, jsdom, ESLint.
3. **The backend sidecar exists three times (≈135 MB).** `backend/build`,
   `backend/dist`, `desktop/binaries` and `desktop/target/*/binaries` all hold
   copies of the same PyInstaller output.
4. **`backend/.venv` (≈75 MB).**

## Must be kept (source of truth)

- `backend/app/`, `backend/alembic/` (incl. `versions/` migrations), `backend/tests/`,
  `backend/alembic.ini`, `backend/run_server.py`, `backend/openisave_server.spec`,
  `backend/pyproject.toml`, `backend/requirements*.txt`
- `frontend/src/`, `frontend/scripts/`, `frontend/index.html`, `frontend/*.json`
  config, `frontend/package.json`, `frontend/package-lock.json`, `vite.config.ts`,
  `.eslintrc.cjs`
- `desktop/src/`, `desktop/capabilities/`, `desktop/icons/`, `desktop/build.rs`,
  `desktop/Cargo.toml`, `desktop/Cargo.lock`, `desktop/tauri.conf.json`
- `package.json`, `package-lock.json` (root, Tauri CLI)
- `docs/`, `scripts/`, `README.md`, `.gitignore`, `logo.png`

## Never part of the project folder

`%LOCALAPPDATA%\OpenISave2\data\`, `backups\` and `logs\` hold the real
financial database, its backups and logs. They are not inside the repository,
are not touched by `scripts/clean_build_artifacts.ps1`, and are excluded from
Git and from every release package.

## Cleanup

Run `scripts/clean_build_artifacts.ps1` to remove only the regenerable items in
the table above. See `docs/REPOSITORY_CLEANUP_REPORT.md` for the before/after
result of the 2026-09-22 cleanup.
